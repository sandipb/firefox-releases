# Firefox Releases

Firefox release information and announcements to subscribers.

## Language

**Release**:
A Firefox version with a release date and Mozilla release-notes link, included by the project's existing release selection.

**Announcement**:
A message about a release sent to a destination.

**Destination**:
A specific Discord channel or Mastodon account receiving announcements. Test and production destinations are distinct.
_Avoid_: Channel when referring to both Discord and Mastodon.

**Delivery**:
The outcome of sending one release announcement to one destination. Success at one destination does not imply success at another.

**Baseline**:
Releases treated as already handled when a destination is explicitly activated, without sending announcements for them.

**Superseded delivery**:
An unsent announcement abandoned because a newer release became eligible for that destination.
